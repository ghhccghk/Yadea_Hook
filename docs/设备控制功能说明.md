# 设备控制功能说明

## 功能概述

通过蓝牙连接 DG-LAB 郊狼电击器，根据车速自动控制脉冲强度。

## 主要功能

### 1. 蓝牙设备管理
- 扫描附近的郊狼设备
- 支持 V2 和 V3 版本
- 实时显示连接状态和电池电量

### 2. 用户自定义曲线
- 可视化曲线编辑器
- 拖拽控制点调整车速-强度映射
- 支持添加/删除控制点
- 实时预览曲线效果

### 3. 强度控制模式
- **自动模式**：根据车速自动调节强度
- **手动模式**：手动设置 A/B 通道强度
- **紧急停止**：一键清零所有通道

### 4. 通道选择
- A 通道
- B 通道
- A+B 双通道

## 界面说明

### 导航栏
- **Home**：显示车辆信息和日志
- **Device**：设备控制界面
- **Settings**：设置界面

### 设备控制界面

#### 连接状态区域
- 蓝牙图标显示连接状态
- 设备名称和电池电量
- 版本选择（V2/V3）
- 扫描/连接/断开按钮

#### 强度控制区域
- 自动/手动模式切换
- 自动模式：显示当前配置
- 手动模式：A/B 通道强度滑块
- 紧急停止按钮

### 设置界面

#### 速度警报设置
- 警报阈值（km/h）
- 触发间隔（秒）
- 自定义音频文件

#### 设备控制设置
- 启用/禁用设备控制
- 通道选择
- 最大强度限制（0-200）
- 车速-强度曲线编辑器

## 曲线编辑器使用

### 基本操作
1. **选择控制点**：点击曲线上的点
2. **移动控制点**：拖拽选中的点
3. **添加控制点**：点击"添加点"按钮
4. **删除控制点**：点击点旁边的"删除"按钮

### 曲线规则
- 第一个点（0 km/h）和最后一个点的 X 坐标固定
- 控制点不能越过相邻点
- 至少需要 2 个控制点

### 默认曲线
```
0 km/h → 0%
10 km/h → 0%
15 km/h → 20%
25 km/h → 50%
35 km/h → 80%
50 km/h → 100%
```

## 工作流程

```
1. 打开应用，进入 Device 页面
2. 选择设备版本（V2/V3）
3. 点击"扫描设备"
4. 从列表中选择设备连接
5. 进入 Settings 页面配置曲线
6. 返回 Device 页面，选择"自动模式"
7. 开始骑行，强度将根据车速自动调节
```

## 安全注意事项

1. **首次使用**：先用低强度测试
2. **最大强度**：建议不超过 100（总范围 200）
3. **紧急停止**：随时可用，一键清零
4. **断开连接**：离开时记得断开设备

## 配置存储

所有设置保存在 SharedPreferences 中：

### speed_alert_prefs
- `speed_threshold`：速度阈值
- `cooldown_ms`：触发间隔
- `audio_path`：音频文件路径

### speed_strength_curve
- `enabled`：是否启用设备控制
- `channel`：控制通道
- `max_strength`：最大强度
- `curve_points`：曲线控制点 JSON

## 故障排除

### 无法扫描到设备
- 检查蓝牙是否开启
- 确认设备在范围内（<10米）
- 尝试重启蓝牙

### 连接失败
- 确认设备版本正确（V2/V3）
- 检查设备是否已连接其他手机
- 重启设备后重试

### 强度不变化
- 检查是否在自动模式
- 确认曲线配置正确
- 检查最大强度设置

### 电池电量不显示
- 仅 V3 版本支持
- 需要连接后才能读取

## 技术细节

### BLE UUID
**V3 版本**
- 服务：0000180C-0000-1000-8000-00805f9b34fb
- 写入：0000150A-0000-1000-8000-00805f9b34fb
- 通知：0000150B-0000-1000-8000-00805f9b34fb
- 电池：00001500-0000-1000-8000-00805f9b34fb

**V2 版本**
- 服务：0000ffe0-0000-1000-8000-00805f9b34fb
- 写入：0000ffe1-0000-1000-8000-00805f9b34fb
- 通知：0000ffe2-0000-1000-8000-00805f9b34fb

### B0 指令格式
```
0xB0 (1byte) + 序列号 (4bits) + 强度解读方式 (4bits) + A通道强度 (1byte) + B通道强度 (1byte) + A通道波形频率 (4bytes) + A通道波形强度 (4bytes) + B通道波形频率 (4bytes) + B通道波形强度 (4bytes)
```

### 强度解读方式
- 0b00：不改变
- 0b01：相对增加
- 0b10：相对减少
- 0b11：绝对设置
